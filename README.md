# Deskora – Interactive Web Desktop Environment

**Deskora** is a macOS-inspired interactive web desktop environment built with React.js. It transforms a traditional portfolio website into a desktop-like experience where users can interact with multiple application windows, explore projects, view documents, listen to music, and access a terminal interface — all within a single browser.

The goal of Deskora is to create a modern, immersive, and interactive digital workspace that combines creativity, functionality, and a desktop operating system experience.

## ✨ Features

- **Desktop Environment:** A macOS-inspired interface with a clean and modern desktop layout.
- **Multi-Window Interface:** Open and interact with multiple application windows.
- **Portfolio Window:** Explore personal information, skills, projects, and professional experience.
- **PDF Viewer:** View documents and PDF files directly within the desktop environment.
- **Music Player:** Enjoy music through an integrated Spotify-inspired music interface.
- **Terminal:** Access a terminal-style interface for an interactive command-line experience.
- **Dock Navigation:** Quickly access applications through a macOS-inspired dock.
- **Window Controls:** Interact with application windows using desktop-style controls.

## 🚀 Getting Started

Follow these steps to run Deskora locally.

### Prerequisites

Make sure you have the following installed:

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/jawadarshad007/deskora.git
```

### 2. Navigate to the Project Directory

```bash
cd deskora
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore Deskora.
